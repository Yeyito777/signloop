ASL static alphabet model and feature extractor attribution

Source: https://github.com/Siruyy/realtime-asl-recognizer
Revision: 74b976b536ab8318dab756a3071a681d5c75bcb0
Data: data/processed_v2 (24 static classes, J/Z excluded).
Feature extractor: src/feature_engineer.py.

Signloop modifications: new MLP trained from these labeled coordinates using
backend/alphabet_train.py, train-only normalization and internal validation,
native Swift/Accelerate inference and feature extraction, explicit letter
confirmation. No pickle/TensorFlow runtime. The original published model was
evaluated but is NOT bundled. Only 24 static letters are modeled; J/Z are not
detected. The dataset has no signer/session IDs: neither its sample-split result
nor the author's claims establish held-out-signer or live phone accuracy.
